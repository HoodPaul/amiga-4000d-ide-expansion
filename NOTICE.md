# Project collaboration and supplied artwork

This black-PCB project is a collaboration between Paul of UK Computing Limited,
Jon of JMC Electronics, and AI assistance through Codex.

The UK Computing and JMC logos are supplied project artwork. Please retain both
logos in their existing underside positions on shared designs and manufactured
boards, and retain the project credits. Their inclusion does not grant permission
for unrelated use of either brand or logo.

No project-wide standard licence has been selected. Public availability does not
by itself assign a standard hardware or software licence. Ask the maintainers
about permissions for uses beyond the supplied project terms.

## KiCad library material

The connector and diode footprint libraries use KiCad Community footprint material
from KiCad 7.0.11. These library files are provided under CC BY-SA 4.0 with the
KiCad library exception. The complete supplied notice is retained in
[licences/KiCad_Footprints_Licence.txt](licences/KiCad_Footprints_Licence.txt).

Project-local changes include narrower printing outlines, concealed pin-1
triangles and printing stroke widths. The KiCad library exception applies to
electronic designs using the library material; it does not assign a licence to
the entire project or to the supplied logos.

Amiga and other product names identify intended compatibility. No manufacturer
endorsement is claimed.
