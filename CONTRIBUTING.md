# Contributing

1. Read AGENTS.md, the current handover and the relevant engineering guide.
2. Work on a focused branch and preserve unrelated edits.
3. Use the delivered CAD as the starting point. Keep the submitted revision 0.1 fabrication package unchanged.
4. Run the checks appropriate to the change and report their scope. Record any native DRC findings without hiding them.
5. Update the handover, authoritative guide and changelog where relevant.
6. Open a PR explaining the change, validation and manufacturing or hardware impact.

Retain the collaboration, artwork and KiCad library notices. Do not infer
hardware compatibility or operating results from a successful data audit.
Use British English and omit private order, account and customer information.
